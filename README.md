# Ali Raza — Personal Portfolio

Source repository for [amrshah.github.io](https://amrshah.github.io), a lightweight static portfolio covering software engineering, product R&D, SaaS architecture and technical leadership.

## Stack

- Static HTML, CSS and JavaScript
- GitHub Pages hosting
- GitHub Actions deployment

## Development

Open `index.html` in a browser or serve the repository root with any local static server. No package installation or build step is currently required.

## Deployment

Changes merged into `master` trigger the workflow in `.github/workflows/deploy-pages.yml`. Pull requests targeting `master` validate the Pages artifact without deploying it.

See [how-to-guide.md](./how-to-guide.md) for repository structure, deployment details and future CMS direction.
